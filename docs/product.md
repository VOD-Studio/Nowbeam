# 首版产品规格

状态：产品选择已由用户逐项确认；其余工程选择依据用户“剩下选择最优解”的授权裁定。原生客户端与可选接收服务已有真实实现和开发运行证据；本文仍是完整交付边界，不把已实现等同于全部验收通过。构建、启动及原生操作步骤见[根目录 README](../README.md)，当前验收缺口见第 7 节。

## 1. 交付物与使用方式

1. 原生 macOS 菜单栏软件及设置窗口：设置来源、隐私、预览与多个接收端，查看每个连接的成功确认和错误。
2. 通用 WSS + JSON 上报协议及接入文档：接收方自行实现接口，软件直连，不要求安装 Nowbeam 服务。
3. 可选独立接收服务：单所有者、多设备，可自托管，提供当前状态读取，不记录活动历史。它是可用的协议实现，不是强制中转。

软件内完成日常配置。为 Nowbeam 独立接收服务提供的所有者管理能力也放在原生设置界面，使用与设备上报权限分离的管理凭证；第三方接收端的账号和凭证签发由对方负责。不能要求第三方为了接收状态实现 Nowbeam 的整个管理接口。

不另做 Web 后台、公开状态页、嵌入卡片或 CLI 产品。服务器安装、容器启动与开发校验允许使用命令行，但不替代图形化产品功能。

## 2. 平台与来源

| 项目 | 首版边界 |
| --- | --- |
| 桌面系统 | macOS 15+、Apple Silicon；Intel、Windows、Linux 不在首批交付，契约保持平台无关 |
| 软件形态 | AppKit 菜单栏入口，SwiftUI 设置；安装包为独立 `.app` / DMG，不以 Mac App Store 上架为目标 |
| 前台应用 | 当前真实前台应用的允许公开名称；不固定软件名，不从名称推断其他活动 |
| 窗口信息 | 当前聚焦窗口的标题；同一应用内换窗口、改标题也必须更新 |
| 媒体 | QQ 音乐、网易云音乐的实际媒体会话；播放与暂停、曲目变化、停止、退出均需验收 |
| 媒体字段 | 曲名、可用的艺人/专辑、播放器展示名、播放状态、可靠时长与位置；缺失数据用 `null` |
| 媒体范围 | 当前系统选中的有效会话且属于明确支持的播放器；不同时拼接两款播放器的会话 |
| 未纳入媒体范围 | 账号登录、曲库/收藏/历史、封面托管与抓取、浏览器扩展、远程播放控制 |

最低版本是开发兼容目标，不是测试结果。发布前必须有对应系统与播放器的实测记录；没有某个环境就不能宣称已验证该组合。首版验收不能用 Apple Music / Spotify 替代 QQ 音乐或网易云音乐。

允许仅媒体模块使用系统私有媒体接口。不得为了兼容而读取 Cookie、播放器历史/缓存、注入播放器进程、关闭 SIP 或降低系统安全设置。接口不可用时明确显示来源不可用，并清除媒体字段，不回填上一首歌。

## 3. 首次配置与日常操作

- 首次运行整体分享与来源均关闭，后续每次启动也强制暂停整体分享。保留的来源配置可用于本地预览，不自动授权恢复活动发送。用户选择本地来源，必要时主动授权，查看脱敏预览，启用目标后再明确恢复分享。
- 添加接收端时配置完整 `wss://` 地址和设备凭证，目标默认不启用。连接检查只验证协议和身份，收到 welcome 后关闭，不接管已有设备、不提前发送活动；分享需要独立确认。
- 支持同时启用多个接收端。每个目标拥有独立凭证、连接、确认状态和错误；不共享跨站设备标识。
- 全部目的地接收同一份隐私过滤结果；首版不做逐目的地字段映射或不同隐私规则。
- 修改地址或更换身份按新的目的地授权处理，替换后目标不启用，不能自动把旧凭证和已启用分享迁移到新域名。
- 菜单栏提供整体暂停/恢复、当前允许公开的内容和连接概况。设置中提供来源、窗口白名单、应用隐藏规则及目的地列表。
- “已经发送”与“接收方已确认”分开呈现；没有 ACK 不能显示同步成功。

## 4. 隐私默认值

- 开启应用来源后，应用名称默认允许，用户可隐藏指定应用。隐藏应用也隐藏其窗口标题；媒体开关独立，不因此自动关闭媒体。
- 窗口来源默认关闭。开启后仍必须命中按稳定本地应用身份管理的白名单；无权限、无焦点窗口或读取失败时为空。
- 过滤在客户端发生。未允许的标题不能进入上报消息、发送队列或诊断日志；来源关闭后应停止相应读取。
- 不采集屏幕截图、键盘内容、网页正文、音频内容或硬件指纹。
- 凭证放 Keychain；普通配置只保存凭证引用。每个接收端的设备身份和凭证独立，所有者管理凭证另行存储且不能替代设备令牌。接收服务保存高熵令牌的校验值，不记录令牌明文。
- 不保留本地或服务端活动历史；允许不含内容的连接诊断。未来如增加历史必须重新作出明确产品决策。
- 首次开启独立接收服务的匿名读取需所有者确认。客户端启用上报不等于授予第三方公开许可；接收方必须另行落实其公开策略。
- 用户必须知道：接收方可以另行保留已经收到的数据；Nowbeam 无法保证删除第三方已保存的副本。

## 5. 生命周期

| 事件 | 必须行为 |
| --- | --- |
| 无前台应用、窗口或媒体 | 相应字段为 `null`，不制造占位活动 |
| 应用/窗口/媒体关闭或权限撤销 | 停止相应采集，清除该来源，其他允许的来源继续 |
| 媒体暂停 | 保留有效暂停会话，播放速率为零，不推进进度 |
| 媒体结束、退出或无法确认有效 | 清除媒体，不把旧曲目解释为暂停 |
| 锁屏或无法确认安全会话 | 停止全部采集，预览与发送均为空；仍能保活时设备可以保持在线 |
| 暂停整体分享 | 清除全部活动，保留空快照保活以区分在线和活动；界面说明此行为 |
| 禁用某个目的地 | 尽力发空快照再关闭该连接，不再自动连接该目标 |
| 睡眠、软件退出 | 有限时间尽力清空并关闭，不无限阻塞退出；租约负责异常兜底 |
| 网络中断 | 不积累活动历史；无法及时撤回时，接收方在租约到期清除 |
| 重连、解锁、唤醒 | 重新验证采集许可和当前状态，不重放离线期间活动 |
| 凭证撤销 | 接收方立即隔离连接、删除其公开活动，客户端停止重连并提示重新授权 |

锁屏保护使用公开 `CGSessionCopyCurrentDictionary` 返回字典中的未文档化 `CGSSessionScreenIsLocked` 字段。macOS 27 实测该键仅在锁屏期间出现（伴随 `CGSSessionScreenLockedTime`），解锁后整个键消失；因此标志存在即判定锁屏，键缺失视为未锁，字典整体不可得或公开会话键异常时 fail-closed 停止采集。分布式会话通知实测不可依赖，只用于触发复核，不作为可靠锁屏结论；每次发送前仍重新确认。该语义依赖系统行为，升级后必须重新实测锁定与解锁转换，不能仅凭空快照宣称生命周期验收通过。

客户端将采集期限与发送后 ACK 期限分开（各 5 秒），首快照期限 10 秒、常规保活间隔 15 秒。每个目的地只保留一份在途消息和最新待发状态，不因慢采集或网络卡住无限排队。接收端以新接受快照的 45 秒租约兜底；同序重试、传输 Ping/Pong 都不续租。这些期限不是端到端延迟 p95 已达标的证明。

## 6. 独立接收服务与消费者

- 一个实例一个所有者，支持多台独立授权的设备；不做自助注册、多租户、组织或团队监控。
- 接收方按设备独立保存当前快照。公开 API 返回获准公开的设备状态，由消费者选择一台或并列展示。
- 不自动选最近设备，不把 A 设备的应用和 B 设备的媒体拼接。
- 匿名读取默认关闭；开启后任何能访问入口的人都可能读取。CORS 域名限制不是身份鉴权。
- 管理凭证与设备上报凭证分开；上报凭证不能配置实例、列出私有设备或撤销其他设备。
- 首次初始化仅成功一次，返回独立所有者凭证；所有者凭证和新设备凭证各只在签发时返回。原生软件保存到 Keychain，用户应安全备份所有者凭证。丢失管理凭证不会重新开放初始化；旧初始化令牌不能登录或恢复管理权限。
- 第三方可以用任意后端实现上报协议，并自行决定网站读取方式。SSE / WebSocket 展示推送不是通用上报协议的前提。
- 首版独立服务提供 HTTP JSON 当前状态读取，不额外提供浏览器推送、Webhook 或展示组件。

## 7. 首版验收标准

以下标准保留为完整首版验收门槛，必须逐项观察，不得仅凭单元测试、投影测试或协议示例宣称通过：

1. 软件可作为原生 `.app` 启动，菜单栏和设置操作完整，不要求使用者靠 CLI 配置日常功能。
2. 真实切换前台应用、在同一应用切换窗口及修改标题，都能正确更新；标题关闭或未获白名单允许时不读取/上报标题。
3. QQ 音乐、网易云音乐分别验证播放、暂停、恢复、换曲、结束、退出，以及有应用无媒体、仅媒体、全空三种组合。
4. 两个独立接收端同时接收；停止其中一个、令其返回错误或撤销其凭证，另一个仍能收到更新。
5. 锁屏、关闭来源、撤销权限、暂停分享后旧内容被清除；正常网络下变化到确认的目标延迟 p95 不超过 3 秒。
6. 服务端观测到断开时主动清除；异常网络下没有新快照超过 45 秒必须过期。仅有 Ping/Pong 不得延长活动有效期。
7. 旧连接、旧序号、同序号不同内容和旧关闭回调，均不得覆盖或删除新连接的状态。
8. 接收服务重启后不恢复旧活动；客户端重新建立连接并采集当前状态。
9. 多设备公开结果各自独立；全空活动仍可在线；公开入口关闭、凭证撤销及读取时到期检查都生效。
10. 日志、普通配置、测试报告和公开响应不泄露令牌、原始标题、进程路径、硬件指纹或未允许内容。
11. 使用 HTTPS/TLS 的真实连接验证证书错误、协议不匹配、超大消息与非法消息；不得通过关闭证书验证让测试通过。
12. 正式安装包签名与公证必须使用维护者授权的身份；开发签名、未签名运行和正式可发布状态必须分清。

### 当前证据与未验收项

- **已观察**：macOS 27 / Apple Silicon 的真实原生四页设置、管理界面、菜单暂停及正常退出；退出后接收端离线且字段为空。即使磁盘配置为 `sharingEnabled=true`，再次启动仍明确暂停。两个接收端的 ACK、暂停空快照、停一端不重连另一端、Keychain 保存/读取/删除、原生所有者初始化及设备管理均已实际运行。
- **已测试**：Go 竞态测试、vet、构建；Swift Debug 为 22 个 Core + 12 个 Capture 测试，Release 为 16 个 Core + 12 个 Capture 测试（回环连接生命周期组仅 Debug）。真实链路包含约 45.035 秒过期、重复快照不续租、接管隔离、撤销、权限边界与不可信 WSS 证书拒绝；未改变系统信任。测试范围不等于全部用户操作已验收。
- **系统会话已实测**：macOS 27 解锁桌面下真实采集贯通（前台应用随切换在 cmux、Code、Nowbeam 间真实变化），锁屏立即清空全部来源并以空快照保活（设备仍在线），解锁后恢复真实采集；锁屏期间持续播放的曲目在上报时使用真实最新位置，不推断进度。此前"键缺失即 fail-closed"的实现使解锁桌面永久无法采集，已按实测语义修复并附纯函数测试；AppKit 自动终止曾使无窗口的常驻进程被系统静默回收，已在入口禁用并在打包清单声明。辅助功能未授权，窗口标题采集与权限授予/撤销仍未验收。
- **播放器部分实测**：QQ 音乐 11.10.5 真实播放、暂停恢复、曲目推进与换曲（含《人间不值得》《孽海记》两曲目）经接收端快照确认；播放器退出清除尚未逐项记录。常见目录及系统应用注册表仍未发现网易云音乐，其完整生命周期不能据此判定通过。
- **开发产物与容器**：Release `.app` / `.dmg` 已构建，应用为 ARM64、ad-hoc、未公证；Linux/ARM64 scratch 镜像及受限非 root Compose 实例已运行。强制终止持有合成活动的容器再启动，所有者和设备身份保留，活动、时间戳与租约不恢复，初始化入口仍关闭。
- **其他交付缺口**：睡眠/唤醒转换、端到端延迟 p95、macOS 15 实机、系统信任下的正式 WSS 接收部署、正式签名包媒体运行、Developer ID 签名与公证仍未验收。远端 CI 尚未运行；开发产物不等于正式可发布版本。
