# Storage 约定

上层约定：[internal/AGENTS.md](../AGENTS.md)。

- SQLite 只保存实例公开配置、独立设备身份/名称/创建时间、SHA-256 凭证校验值。绝不保存活动或最后快照。
- 凭证由 crypto/rand 产生，验证哈希使用常量时间比较；setup 是数据库原子的单次插入，不允许首访者抢注。
- 专用目录 0700、数据库与锁文件 0600，拒绝符号链接及第二实例同时占用。平台目标为 Linux 与 macOS。
- 写入始终参数化，管理数据变更必须单条原子语句或明确事务；业务授权与连接状态不进入本包。
- SQLite 与所有静态嵌入组件的许可证必须随二进制保留；不能仅标注公有领域。
