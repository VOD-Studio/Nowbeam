# Wire 约定

上层约定：[internal/AGENTS.md](../AGENTS.md)。

- 以仓库公共 v1 Schema 为准，字段名区分大小写；每一层完整字段校验必须保留。
- 先限制完整消息大小，再验证 UTF-8、代理转义、重复键和数值；不能直接宽松解码到 Go struct。
- 字符串长度按 Unicode 码点计算。时间只接受真实 UTC 日历值、秒或 1–3 位小数。
- 整数与速率比较必须精确，不允许 float64 舍入把越界值放行。指纹按语义规范化，不能依赖 JSON 原文键顺序。
- 出站时间统一毫秒 UTC；来源三个键始终存在，null 不省略。不得新增采集原始字段。
