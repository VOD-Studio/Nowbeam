# 独立接收服务约定

上层约定：[根目录 AGENTS.md](../AGENTS.md)。

- 本目录只交付可选独立接收服务，不建设 Web 管理后台，不成为客户端的强制中转。
- 管理、读取、上报的权限独立；日常所有者操作由原生软件调用管理 API。
- 服务代码位于 [receiver](receiver/README.md)，进入后先读 [当地约定](receiver/AGENTS.md)。
- 一个实例一个进程、一个私人 SQLite 目录；不得把共享文件或多副本假装成高可用方案。
- 不保留活动历史、不记录消息内容或凭证。永久协议行为变更必须同步公共协议与两端实现。
- 并行编辑期间不执行构建、测试、格式化；统一由集成负责人在全部编辑落地后执行。
