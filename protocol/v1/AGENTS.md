# v1 消息契约

- Schema 使用 JSON Schema 2020-12；字段使用 camelCase，所有对象拒绝未知属性，三个来源键必须显式存在。
- `message.schema.json` 不描述连接状态机；不要为了让 JSON 示例通过而删掉规范中的时序约束。
- `examples.json` 每个顶层值是一条独立消息，不是一段可重放的活动历史；每个消息都必须通过 Schema 与静态语义校验。
- 正反例关注清除、独立来源、暂停速率、未知位置和输入边界，不能使用真实用户状态。
- 修改后统一运行根目录 `make check`，不要更新示例来掩盖消费者可见的契约破坏。
