# 通信契约

- `README.md` 是线协议与跨消息语义，`v1/message.schema.json` 是单消息结构，`v1/examples.json` 是明确虚构的示例。
- 用户选择了 WebSocket + JSON；不能为方便改回 HTTP 上报。管理/公开读取 HTTP 接口不等于上报接口。
- 身份、连接代次、顺序、过期、权限和重连规则不能仅靠 JSON Schema 验证；不得把静态校验当状态机或网络验证。
- 必须同时检查客户端和接收端契约；未知原始字段不得默默通过，null 必须保留清除含义。
- 任何不兼容变更都要处理子协议版本，不建立 v1 的静默兼容分支。
- 示例不能使用真实活动、主机名、账号、令牌或访问地址。变更完成后统一运行根目录 `make check`。
