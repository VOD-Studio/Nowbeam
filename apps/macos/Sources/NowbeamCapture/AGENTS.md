# 本地系统采集

- AppKit / Accessibility 读取只在 MainActor。窗口先检查来源、白名单、隐藏规则与权限，再请求 AX 属性；关闭来源立即移除观察。
- 媒体辅助进程仅调用只读 `get` / `stream`，绝不调用播放控制，不记录原始输出。使用包内资源的绝对路径，不依赖 shell 或 PATH。
- 不支持的播放器、缺失会话、读取失败、进程退出、过期信息必须转为空；未知进度、速率不能推断成固定值。
- 对外只提供过滤后的来源与不含活动的诊断。系统状态无法确认时停止公开；不要用睡眠或应用失焦冒充已证明锁屏。
